# Shinarae Store Data Analysis – Excel Project

This project involves the analysis of sales data for **Shinarae Store** in 2024 to identify trends in customer behavior and help improve sales performance in 2025. The report was created using Microsoft Excel with advanced functions, pivot tables, and visualizations.

## 📊 Objective

To generate a comprehensive annual sales report that helps Shinarae understand customer preferences, top-selling products, and seasonal trends, and use these insights to make better business decisions for the upcoming year.

## 🛠 Tools Used

- Microsoft Excel
  - Pivot Tables
  - Charts & Graphs
  - Data Cleaning
  - Forecast Sheet

## 🔍 Key Insights

- Monthly sales trends across the year
- Top-performing product categories
- Customer purchasing behavior
- Sales forecasting for 2025

## 📁 Files Included

- `Customer Behavior and Sales Trends Analysis – Shinarae Store 2024.xlsx`: Excel workbook with raw data, cleaned data, pivot tables, charts, and final dashboard.

## 📈 Outcomes

This analysis helps Shinarae:
- Understand peak sales months and slow periods
- Identify high-demand products
- Prepare data-driven strategies for inventory and promotions in 2025
